# Math Adventure Island 🏝️

A fun, colorful mathematics game and quiz web app based on **Singapore's Primary 1 Math syllabus**. Designed for 7-year-olds with 52 weekly levels covering the complete curriculum.

## Features

- **52 Levels** — one for each week of the year, ~1 hour per session
- **Full Singapore P1 Syllabus** — Numbers, Shapes, Measurement, Money, Multiplication, Division, Graphs
- **Character Customization** — choose hair, skin tone, outfit, and accessories
- **4 Themed Zones** — Number Forest, Shape Beach, Measure Mountains, Math Kingdom
- **13+ Question Types** — counting, comparing, number bonds, addition, subtraction, shapes, clocks, money, graphs, and more
- **Reward System** — stars (1-3 per level), gems, and 11 unlockable pet companions
- **Progress Saving** — automatically saved to browser localStorage
- **Streak Bonuses** — consecutive correct answers earn bonus gems
- **Procedural Questions** — questions are generated with randomization for replayability

## Syllabus Coverage

| Zone | Weeks | Topics |
|------|-------|--------|
| 🌳 Number Forest | 1–13 | Counting, number words, comparing, ordering, number bonds, addition & subtraction within 10 |
| 🏖️ Shape Beach | 14–26 | 2D & 3D shapes, patterns, numbers to 20, addition & subtraction within 20 |
| ⛰️ Measure Mountains | 27–39 | Length, mass, capacity, numbers to 40, telling time |
| 🏰 Math Kingdom | 40–52 | Money, multiplication, division, numbers to 100, picture graphs |
